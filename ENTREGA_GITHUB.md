# Etapas finais da Semana 3

1. Testar o projeto pela IDE ou seguir os comandos do README.
2. Extrair a pasta `TocoFome_Semana3_Simples` em um local fácil de encontrar.
3. Criar um repositório vazio chamado `TocoFome` no GitHub (não marcar para criar outro README ou licença).
4. Abrir Git Bash ou terminal na pasta do projeto e executar:

```bash
git init
git add .
git commit -m "Adiciona estrutura inicial do TocoFome"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/TocoFome.git
git push -u origin main
```

Substitua `SEU-USUARIO` pelo usuário real do GitHub.

5. No repositório publicado, abrir Settings → Collaborators → Add people, procurar `elmano@gmail.com` e enviar o convite.
6. Copiar o link real do repositório para a atividade. O convite só estará concluído quando for enviado; o professor ainda precisará aceitá-lo.
